# Mist
Welcome to Mist — Your Ultimate Browser Gaming Library

Step into a sleek, Steam-inspired gaming hub built to play directly in your browser. Powered by custom web ports and optimized HTML5 technology, Mist bypasses network restrictions to deliver full, uninterrupted access to over 180+ high-quality titles.

Discover everything from fast-paced action games and atmospheric indie gems to precision platformers and timeless strategy classics—no downloads, installations, or admin rights required. Experience high-frame-rate performance, intuitive controller & keyboard support, and a clean, dark-themed interface designed by gamers, for gamers.

Browse the library, click play, and jump straight into the action on Mist.
